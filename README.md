# Sistema gerenciador de biblioteca
## O sistema cadastra livros, tem funcionalidades de empréstimo e devolução de livros, cria uma lista organizada por titulo, autor ou ano, e busca livros específicos.
### Feito em Python com arquivo CSV.

## Utilização:
- Com o código em mãos, pressione em 'Executar arquivo Python'.
- O Terminal dá instruções com números.
- O código pode ser sensível em relação à opções inválidas, tome cuidado!

## Funcionalidades:
- Cadastro: Informe o titulo, autor, ano de publicação e código ISBN, que é escolhido na hora do cadastro.
- Empréstimo: Informe o código ISBN do livro desejado, caso só haja 1 livro com o código ISBN colocado, ele contabilizará como emprestado imediatamente!
- Devolução: Assim como a devolução, caso haja apenas 1 livro com o código inserido, o livro será contabilizado como 'Disponivel' na hora!
- Lista: Ao chamar a função de listagem de livros, escreva como deseja que os livros sejam ordenados. Caso sua resposta seja inválida, o sistema vai listar por ordem de cadastro automaticamente.
- Sair: Para sair do sistema, aperte 6 no menu principal.

## Requisitos técnicos:
- Aplicação de conhecimento simples de Python.
- Aplicação de conhecimento simples de arquivos CSV.
- Habilidades de resolução de problemas.
